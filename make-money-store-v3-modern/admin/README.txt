ADMIN PANEL
===========

To open the admin panel from this folder:
1. Double-click open-admin.bat
2. It starts the FastAPI server and opens:
   http://127.0.0.1:8000/admin

You can also double-click index.html for the visual interface. For its API buttons
to work, the FastAPI server must already be running.

The admin page is intentionally password-free for local use. Do not expose it
publicly without adding authentication.
